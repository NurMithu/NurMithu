<h2 align="center">🚀 Featured Projects</h2>

### 📉 Customer Churn & Lifetime Value Analysis

**Predicting customer churn and estimating customer lifetime value for a subscription retail business.**

A comprehensive analytical project covering data quality assessment, exploratory analysis, statistical testing, feature engineering, predictive modeling, and business recommendations.

**Approach**

* Logistic Regression for churn prediction
* Multiple Linear Regression for lifetime value
* Statistical testing and feature analysis
* Business-oriented threshold optimization

**Result**

> 🎯 **ROC AUC: 0.789**

The churn decision threshold was explicitly tuned for **early-warning retention outreach** rather than simply using the default classification threshold.

**Tech:** `Python` `pandas` `scikit-learn` `statsmodels`

📂 **Repository:** [Zephyr_Retail_Churn_CLV_Analysis](https://github.com/NurMithu/Zephyr_Retail_Churn_CLV_Analysis)

---

### 📈 Retail Sales Forecasting & Promotion Impact

**End-to-end forecasting analysis across 1,115+ retail stores.**

Three different approaches were evaluated using a time-based holdout rather than assuming a particular model would perform best.

**Models**

* Linear Regression
* Random Forest
* XGBoost

**Results**

> 📊 **XGBoost R²: 0.926**
> 📉 **~40% RMSPE reduction vs. linear baseline**
> 📈 **~39% measured average sales lift associated with promotional activity**

The project combines forecasting with business interpretation to help understand **sales drivers, promotional effects, and store-level demand**.

**Tech:** `Python` `pandas` `XGBoost` `Random Forest` `Streamlit`

📂 **Repository:** [sales-forecasting-rossmann](https://github.com/NurMithu/sales-forecasting-rossmann)

🚀 **Live Demo:** [Open Interactive Forecasting App](https://sales-forecasting-rossmann-2vkhappr8sgdidmbvkorvl.streamlit.app/)

---

### 🛡️ Credit Card Fraud Detection

**Imbalanced classification and unsupervised anomaly detection for financial transactions.**

With fraud representing less than 1% of transactions, standard accuracy can be misleading. This project focuses on **precision, recall, threshold calibration, and anomaly detection**.

**Approaches**

* Logistic Regression
* Random Forest
* XGBoost
* SMOTE-based modeling
* Autoencoder anomaly detection

**Results**

> 🎯 **85% precision at 85% recall** using a business-calibrated Random Forest threshold
> 🤖 **81% of fraud cases detected** using an unsupervised autoencoder

The autoencoder was trained without labeled fraud examples, providing an independent anomaly-detection perspective.

**Tech:** `Python` `scikit-learn` `XGBoost` `SMOTE` `Autoencoders` `Streamlit`

📂 **Repository:** [fraud-detection](https://github.com/NurMithu/fraud-detection)

🚀 **Live Demo:** [Open Fraud Detection App](https://fraud-detection-ywooiuryujcxw7q2ss5hsy.streamlit.app/)

### 💬 Customer Sentiment Analysis

**NLP-based sentiment classification and customer feedback analysis.**

The project compares a simple rule-based baseline with multiple trained machine learning models before applying the strongest model to customer and brand-level analysis.

**Approach**

* Rule-based sentiment baseline
* TF-IDF feature extraction
* Logistic Regression
* Multiple trained classifiers
* Brand benchmarking
* Complaint/root-cause analysis

**Result**

> 📊 **Macro F1: 0.714**
> 📈 **~39% improvement over rule-based baseline (0.513)**

The analysis goes beyond classification to identify **what is driving negative customer sentiment**.

**Tech:** `Python` `NLTK` `TF-IDF` `scikit-learn` `Logistic Regression` `Streamlit`

📂 **Repository:** [sentiment-analysis](https://github.com/NurMithu/sentiment-analysis)

🚀 **Live Demo:** [Open Sentiment Analysis App](https://sentiment-analysis-ytcvdn7yhftrexed7yoczj.streamlit.app/)

<h2 align="center">🎯 My Data Science Approach</h2>

<div align="center">

### Data → Insight → Model → Evaluation → Deployment → Business Impact

</div>

I believe a good machine learning project should demonstrate more than a high accuracy score.

Every major project follows a structured workflow:

**01 — Data**

Real-world, publicly sourced datasets with documented assumptions and data-quality checks.

**02 — Exploration**

EDA, distributions, relationships, missing values, outliers, and statistical investigation.

**03 — Feature Engineering**

Transforming raw variables into meaningful predictive features while avoiding leakage.

**04 — Modeling**

Multiple algorithms are evaluated rather than selecting a model arbitrarily.

**05 — Evaluation**

Performance is measured using metrics appropriate to the business problem — not accuracy alone.

**06 — Interpretation**

Model results are translated into understandable business findings and recommendations.

**07 — Deployment**

Where appropriate, the final model is converted into an interactive application so users can actually interact with the analysis.

**08 — Limitations**

Known weaknesses, assumptions, potential sources of bias, and failure modes are documented.
